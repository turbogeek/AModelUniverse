# Sharing your model

The newsletters end with challenges. Answer one, share it here, and the best answers (and the most
instructive wrong ones) get featured in a future issue.

1. **Fork** this repository.
2. **Add your model** as `submissions/<sheet folder>/<your GitHub name>/<name>.sysml`,
   for example `submissions/09-expressions/ada-lovelace/countWarm.sysml`.
   One package per file. Start with a comment that says which challenge it answers.
3. **Check it.** Run it through a SysML v2 validator or load it in your tool. If something does not
   parse and you can't see why, submit it anyway and say so in the pull request: that is a good question.
4. **Open a pull request** titled `<sheet>: <challenge>` and say in a sentence or two what you tried.

Keep it friendly and on topic. Submissions are published under this repository's license,
CC BY-NC-SA 4.0, so only submit work you are happy to share that way.
