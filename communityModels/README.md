# Community models

Readers' models, one folder per contributor, named with their GitHub ID:
`communityModels/<github-id>/<model>.sysml`.

House rules: funny, correct SysML v2, and clean enough for your mom to read.
Start with the example in [`example-contributor`](example-contributor/countStrong.sysml), then add your
own: [CONTRIBUTING.md](../CONTRIBUTING.md) walks through it step by step, in the browser.
