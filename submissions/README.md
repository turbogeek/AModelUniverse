# Reader submissions

Readers' models, one folder per sheet and one folder per contributor:
`submissions/<sheet>/<github-name>/<model>.sysml`.

Start with the example in [`09-expressions/example-contributor`](09-expressions/example-contributor/countStrong.sysml),
then add your own: [CONTRIBUTING.md](../CONTRIBUTING.md) walks through it step by step, in the browser.
