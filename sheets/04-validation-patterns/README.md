# Sheet 4: Validation Patterns

Model: [`SysMLv2_Validation_Patterns.sysml`](SysMLv2_Validation_Patterns.sysml) (package `ValidationPatterns`). It is the code printed on the cheat sheet, followed by views a tool can render: `fixedVsDefaultView`, `bindSubjectView`, `tradeStudyView`, `importView`, `assumeAssertView`, `testsView`, `noExtendView`, `flowEndsView`, `operatorsView`, `crossSubsetView`.

The cheat sheet itself is in the book *A Model Universe: Cheat Sheets for SysML v2 and the stories behind them*.
