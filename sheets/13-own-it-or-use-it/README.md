# Sheet 13: Own It or Use It

Model: [`SysMLv2_OwnItOrUseIt.sysml`](SysMLv2_OwnItOrUseIt.sysml) (package `BobsBorrowedMower`). It is the code printed on the cheat sheet, followed by a view a tool can render: `ownershipView`.

The cheat sheet itself is in the book *A Model Universe: Cheat Sheets for SysML v2 and the stories behind them*.

## Share your model

Add your own folder, `submissions/13-own-it-or-use-it/<your GitHub name>/`, put your model in it and open a pull request, all in the browser. [CONTRIBUTING.md](../../CONTRIBUTING.md) walks through it step by step with an example, and explains how submissions may be used.
