# Sheet 3: Requirements

Model: [`SysMLv2_Requirements_Examples.sysml`](SysMLv2_Requirements_Examples.sysml) (package `RequirementsExamples`). It is the code printed on the cheat sheet, followed by views a tool can render: `scenarioView`, `constraintsView`, `parametricView`, `truthTableView`, `verificationView`, `bacTestFlow`, `tradeStudyView`, `organizeView`, `timesliceView`, `bobsDayFlow`.

The cheat sheet itself is in the book *A Model Universe: Cheat Sheets for SysML v2 and the stories behind them*.
