# Sheets 1 and 2: SysML v2 Cheat Sheet and Beyond the Basics

Model: [`SysMLv2_CheatSheet_Examples.sysml`](SysMLv2_CheatSheet_Examples.sysml) (package `CheatSheetExamples`). It is the code printed on the cheat sheet, followed by views a tool can render: `defUsageView`, `specializationView`, `photoFlow`, `lampStates`, `portsView`, `requirementView`, `textualView`, `mathView`, `originView`, `crossSubsetView`, `metadataView`, `lifeStates`, `reactionsFlow`, `useCaseView`, `caseFamilyView`, `testCaseView`, `analysisView`.

The cheat sheet itself is in the book *A Model Universe: Cheat Sheets for SysML v2 and the stories behind them*.
